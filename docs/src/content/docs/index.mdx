**AvantiPoint Aspire** is a family of [Aspire](https://aspire.dev) integrations that let you model, provision, and deploy real cloud resources from your AppHost — beyond the built-in Azure path. The first integration targets **Cloudflare**.

## Cloudflare at a glance

Every service targets the real Cloudflare service by default, and most offer a credential-free local dev loop via `.RunAsEmulator()`.

<CardGrid>
  <Card title="R2 object storage" icon="cloud-download">
    S3-compatible buckets + an `IR2Client`. Local **MinIO** emulator.
  </Card>
  <Card title="D1 database" icon="seti:db">
    Serverless SQLite + an `ID1Client`. Local **SQLite** emulator.
  </Card>
  <Card title="AI" icon="comment-alt">
    `IChatClient` / `IEmbeddingGenerator` over Workers AI & AI Gateway. Local **Ollama** emulator.
  </Card>
  <Card title="Vectorize" icon="puzzle">
    Vector database for embeddings / RAG + an `IVectorizeClient`. In-memory emulator.
  </Card>
  <Card title="Workers KV" icon="list-format">
    Key-value store + an `ICloudflareKVClient`. In-memory emulator.
  </Card>
  <Card title="Queues" icon="random">
    Message queue + an `IQueueClient`. In-memory emulator.
  </Card>
  <Card title="Workers" icon="rocket">
    Run hand-authored Workers locally with `wrangler dev`; deploy with `aspire deploy`.
  </Card>
  <Card title="Containers" icon="seti:docker">
    Build a container image from your .NET project and run it on Cloudflare Containers.
  </Card>
  <Card title="Pages" icon="laptop">
    Attach to your Aspire JavaScript app and deploy the build output to Pages.
  </Card>
  <Card title="Hyperdrive" icon="setting">
    Accelerate a production database for Workers — provisioned at deploy.
  </Card>
</CardGrid>
