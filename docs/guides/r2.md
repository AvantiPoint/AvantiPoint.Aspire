# R2 Buckets

R2 is Cloudflare's S3-compatible object storage. The integration provides both a **hosting** side (provision the bucket) and a **client** side (use it from your app).

## Add a bucket (hosting)

```csharp
var cloudflare = builder.AddCloudflareEnvironment();
var uploads = cloudflare.AddR2Bucket("uploads");
```

- **`aspire run`** → a local **MinIO** emulator backs the bucket; it's created automatically. No credentials needed.
- **`aspire deploy`** → the bucket is provisioned in real R2 via the Cloudflare API.

### Options

```csharp
cloudflare.AddR2Bucket("uploads", bucketName: "my-prod-bucket")
    .WithLocationHint("weur")   // R2 location hint
    .RunAsReal()                // use real R2 during `aspire run` (needs credentials)
    .AllowDeletion();           // permit `aspire deploy --destroy` to delete the bucket
```

> [!WARNING]
> Bucket deletion is **off by default** to avoid data loss. `AllowDeletion()` opts a bucket into being removed on destroy.

## Reference it from a service

```csharp
builder.AddProject<Projects.Api>("api").WithReference(uploads);
```

This injects an S3-compatible connection string into the service.

## Use it (client)

In the consuming project:

```csharp
builder.AddR2Client("uploads");
```

This registers an `IAmazonS3` tuned for R2. The same code works against MinIO locally and real R2 in production:

```csharp
app.MapPut("/files/{key}", async (string key, Stream body, IAmazonS3 s3, R2ClientSettings settings) =>
{
    await s3.PutObjectAsync(new PutObjectRequest
    {
        BucketName = settings.BucketName,
        Key = key,
        InputStream = body,
    });
    return Results.Created($"/files/{key}", null);
});
```

## Credentials

- **API token** (provisioning): needs *Workers R2 Storage: Edit* — see [API Tokens](../getting-started/api-tokens.md).
- **S3 credentials** (runtime data access): `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` — see [R2 S3 Credentials](../getting-started/r2-credentials.md).
