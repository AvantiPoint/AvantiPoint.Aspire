# Security

Do not post API tokens, passwords, R2 keys, connection strings or exploit details in public issues. Generated Worker/publish artifacts may embed resolved credentials in plaintext. Do not attach these artifacts or unredacted logs to issues or pull requests. Rotate any exposed credentials.

## Reporting vulnerabilities

Use GitHub's **Report a vulnerability** button on the repository Security tab if private vulnerability reporting is available. A private reporting channel is not currently configured for this repository. If the button is unavailable, open an issue containing only a request for a private reporting channel; wait for a maintainer to provide one before sharing technical details. This document does not promise a response time or support window.
